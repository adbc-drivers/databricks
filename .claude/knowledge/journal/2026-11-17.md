# Learning journal 2026-11-17

### 2026-11-17: Go driver — Databricks query-tag length limit counts UTF-16 code units
**Context:** PR #731 added per-database/connection/statement query tags for the Go driver; the reviewer asked whether arbitrary Unicode is allowed and how the 128-char cap is measured, and the author confirmed against a live warehouse.
**Rule:** Enforce the Databricks query-tag 128-char limit by counting UTF-16 code units (an emoji counts as 2, escaping on the wire counts as zero), not bytes or runes.

### 2026-11-17: Repo tooling — Language-classifier case globs match substrings anywhere in a path
**Context:** PR #772's lesson-tags.sh classified changed paths by language; reviewers found `*rust*`/`*csharp*` globs matched `docs/trust.md` and `entrust.sh`, so the final version anchored to driver dirs and language-named CI/workflow files.
**Rule:** Anchor language/path classifier globs to directory or filename boundaries (`csharp/*`, `ci/scripts/rust*`), never bare `*lang*`, or unrelated paths like `trust.md` get mis-tagged.

### 2026-11-17: Go driver — Keep query-related driver options under databricks.query.*
**Context:** In PR #731 the maintainer steered the new option from `databricks.query_tag.<name>` to `databricks.query.query_tag.<name>` to match the convention of grouping all query-related options.
**Rule:** Name new query-related Databricks driver options under the `databricks.query.` prefix for consistency, and prefer per-item keys over a single CSV value so names needing escaping stay unambiguous.

### 2026-11-17: Reviewer — Verify a review fix actually landed before replying Fixed
**Context:** On PR #731 the reviewer flagged an unneeded full-map copy and a missing lock; the author replied "Updated" twice yet the reviewer kept finding the same code unchanged ("we're still copying the entire map every time", "And I don't see a lock").
**Rule:** Before replying "Fixed"/"Updated" to a review comment, re-read the pushed diff and confirm the change is actually present, especially for concurrency fixes like dropping a copy or adding a lock.
